# Portfolio Développeur Web & Web Mobile

Portfolio professionnel réalisé avec **Symfony 8.1** dans le cadre de mon parcours de Développeur Web et Web Mobile.

## Aperçu

Ce projet présente :

- mon parcours
- mes compétences
- mes projets
- mon CV
- un formulaire de contact
- une interface d'administration sécurisée

Le site est entièrement responsive et disponible en français et en anglais.

## Fonctionnalités

- Portfolio responsive
- Traduction FR / EN
- Gestion des projets
- Gestion des compétences
- Téléchargement du CV
- Formulaire de contact
- Interface d'administration EasyAdmin
- Authentification sécurisée
- Gestion des images
- Base de données MariaDB

## Technologies utilisées

- Symfony 8.1
- PHP 8.4
- Doctrine ORM
- Twig
- EasyAdmin
- MariaDB
- AssetMapper
- ImportMap
- CSS3
- JavaScript
- Git / GitHub
